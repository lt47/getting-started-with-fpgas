## Notes on this Chapter's Example 

In the book, in order to reference the FPGA's signals, we are advised to add a pin constraints file and look up the device's documentation to determine which signals correspond to what pin numbers. 

With the DE-10 board however, this file is called the `.qsf` file. It can be generated by clicking Assignments->Export Assignments from the top menu. 
[Reference](https://www.intel.com/content/www/us/en/docs/programmable/683492/18-1/generating-settings-files.html)

Alternatively, you can view the top level file if you used the `.par` file recommended in the DE-10 Lite Board project folder, called `DE10_LITE_Default.v` to reference the signals. They are the same as what you will find in the `.qsf` file unless manually changed.
